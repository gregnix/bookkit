# Einleitung

Dieses Beispielbuch zeigt die bookkit-Konventionen an einem Minimalfall. Ein
zentraler Begriff wird als [Versionskontrolle]{.index} markiert und landet so
im Stichwortverzeichnis.

Wie die eigentliche Arbeit abläuft, steht im Kapitel
[Grundlagen](#grundlagen) — der Querverweis nutzt den Titel-Anker.

## Aufbau

Überschriften tragen keine Nummern; der Build ergänzt sie. Abschnitte werden zu
Unternummern (1.1, 1.2 …) und erscheinen im Inhaltsverzeichnis.
